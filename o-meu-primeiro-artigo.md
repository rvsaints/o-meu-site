# Bem-vindo ao meu novo site!

Este é o meu primeiro artigo escrito em **Markdown** utilizando o tema **PaperMod**.

## O que vai encontrar por aqui

Neste espaço, vou partilhar ideias, notas e artigos. O Markdown permite formatar o texto de forma muito simples:

- **Texto em negrito**: basta colocar asteriscos duplos à volta das palavras.
- *Texto em itálico*: basta colocar um asterisco de cada lado.
- Listas com marcadores: basta começar a linha com um hífen `-`.
